# typeset.us

**Better line breaks for web text.** Typeset keeps short words like "a",
"the" and "of" from being stranded at line ends, keeps names and numbers
with their words, and avoids one-word last lines, in Chrome, Safari and
Firefox alike. It leaves links, emphasis and React-rendered text exactly as
authored, checks every result after rendering, and keeps the browser's
layout whenever it cannot do better. The engine sets every page of
[typeset.us](https://typeset.us); the argument is at
[typeset.us/essay](https://typeset.us/essay).

Use CSS first: `text-wrap: balance` for headlines, `text-wrap: pretty` for
paragraphs. Add Typeset for grammar-aware breaks, the same result in Firefox
(which has no `pretty`), preserved markup, and results your CI can check. It
does not hyphenate or justify.

The current release, pinned with its integrity hash:

Published pins are permanent: their bytes never change and they are never
removed. Every pin and its hash is in [`public/sri.json`](public/sri.json).
`https://typeset.us/go.js` also works for trying it out; it updates itself
within 4.x and will never move to 5.0. What a version number promises:
[STABILITY.md](STABILITY.md).

The package README covers options, outcomes, React, costs and limits:
[packages/typeset-v4/README.md](packages/typeset-v4/README.md).

## Verification, not vibes

`auditJSON(selector)` reports errors, items to review, and what happened to
every element. A pass requires a nonempty scope with no hard errors or
unprocessed targets; it is not aesthetic certification. Every outcome is
explained in [docs/outcomes.md](docs/outcomes.md). Full contract for agents:
[typeset.us/for-agents](https://typeset.us/for-agents). Read
[support](packages/typeset-v4/SUPPORT.md), including what is not yet tested,
and [migration](packages/typeset-v4/MIGRATION.md).

## This repository

- [`src/lib/v4/`](src/lib/v4): the engine and React adapters.
- [`src/app/`](src/app): the typeset.us website, which runs the same engine.
- [`packages/typeset-v4/`](packages/typeset-v4): the npm package `typeset.us`.
- [`public/go@x.y.z.js`](public), [`public/sri.json`](public/sri.json) and
  [`public/releases/`](public/releases): published loaders, hashes and
  release archives, written only by `npm run release:cut`.
- [`public/releases/published.json`](public/releases/published.json): the
  append-only ledger of every published file; `npm run verify:ledger` fails
  if any of them changes.
- [`docs/`](docs): benchmarks, outcomes, releasing, security advisories.
- [`CHANGELOG.md`](CHANGELOG.md): what changed, including the bugs.

## Develop

```bash
npm run dev           # site at localhost:3000
npm run build:dist    # candidate build from src into output/candidate/; never writes packages/ or public/
npm test              # test:v4: builds the candidate, then runs every suite against it (--only, --list)
npm run test:release  # the same suites against the committed packages/typeset-v4/dist
npm run bench         # benchmark: mount, typesetAll, React, storms, fonts, sizes (docs/BENCHMARKS.md)
npm run release:cut -- --version x.y.z --summary "…"  # the only step that writes a release (try --dry-run)
```
